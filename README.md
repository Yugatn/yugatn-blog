# Yugatn Blog / Блог Югатна

Двуязычный авторский блог (русский / English).

Сайт и публикации в разработке. Ранее опубликованные тексты, презентации и разделы из других проектов **не импортируются автоматически**.

Редакционное правило: новые публикации подготавливаются в отдельных ветках и попадают на сайт **только после явного утверждения автором**.

Источник сайта: `main`. Черновики: `_drafts/` в рабочих ветках. Публикации: `_posts/` после утверждения.

> Это базовая точка для безопасной разработки. Текущая версия репозитория ещё не является запущенным блогом.
